O QR Code Pix pode tornar um pagamento mais prático porque permite que o aplicativo bancário leia informações preparadas pelo recebedor. Em vez de digitar dados manualmente, quem vai pagar escaneia o código e confere a operação antes de autorizar.

O principal cuidado é entender que **gerar um QR Code não equivale a confirmar um pagamento**. O gerador apenas organiza o conteúdo. A transação e sua segurança dependem do banco ou instituição de pagamento envolvidos.

## O que é o Pix estático?

Um QR Code Pix estático pode representar dados de cobrança que se repetem, dentro das possibilidades admitidas pelo padrão utilizado. É uma opção útil em situações como um pequeno comércio ou uma prestação de serviço em que o recebedor quer disponibilizar uma forma de pagamento sem criar uma cobrança individual a cada interação.

No QR Livre, a proposta é gerar um código estático com as informações preenchidas no formulário. O aplicativo não acessa sua conta bancária e não verifica se uma chave Pix pertence à pessoa informada.

## Cuidados antes de gerar

1. Confira a chave Pix e os dados do recebedor, evitando copiar informações de mensagens desconhecidas.
2. Preencha o valor apenas quando houver uma quantia definida; revise a forma como seu banco interpreta o código.
3. Use uma identificação reconhecível para o estabelecimento ou o profissional.
4. Não coloque senhas, dados bancários sensíveis ou informações que não deveriam ser compartilhadas no conteúdo do código.
5. Escaneie o QR Code gerado com um aplicativo bancário confiável para verificar os dados apresentados.

Se imprimir o código em um balcão, observe periodicamente se a imagem original não foi coberta por outro adesivo. Trocas físicas de QR Codes podem redirecionar pagamentos para terceiros.

## Como o pagador deve proceder

Ao escanear, o usuário deve verificar o **nome do recebedor, a instituição e o valor**, quando aplicável, na interface do banco antes de confirmar. Não trate apenas a aparência do QR Code como prova de autenticidade. Em situações incomuns, como nome divergente ou valor inesperado, interrompa e confirme diretamente com o estabelecimento.

Depois do pagamento, o comprovante emitido pela instituição é a referência para a operação. Não basta mostrar a tela de leitura ou dizer que o QR Code foi aberto.

## Evite uma armadilha comum

Um QR Code Pix não é um boleto universal nem garantia de que todos os aplicativos reconhecerão dados preenchidos de qualquer maneira. O padrão possui campos e regras específicas; por isso, faça um teste com o banco que será utilizado e valide a compatibilidade antes de distribuir materiais impressos.

Se precisar emitir cobranças com vencimento, conciliação ou identificação individual de transações, avalie os serviços oficiais da sua instituição financeira. Um gerador de QR Code estático não substitui um sistema completo de cobrança.
