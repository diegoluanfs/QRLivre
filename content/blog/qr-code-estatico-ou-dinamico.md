Ao criar um QR Code para um cartaz, embalagem ou cartão de visita, uma das decisões mais relevantes acontece antes da escolha das cores: o endereço impresso precisará mudar no futuro? Essa pergunta ajuda a decidir entre um QR Code estático e um serviço de redirecionamento dinâmico.

Os dois formatos podem parecer idênticos para quem escaneia. A diferença está no que o código contém e em quem controla o destino ao longo do tempo.

## Como funciona um QR Code estático

O código estático guarda a informação final. Pode ser uma URL, um texto, dados de Wi-Fi ou um payload Pix. Quando a câmera lê o código, ela encontra exatamente esse conteúdo.

Uma vantagem é a independência do serviço gerador: a leitura não exige que o site usado para gerar o desenho continue online. Entretanto, se o QR Code trouxer um endereço que deixa de existir, ele continuará apontando para aquele endereço antigo.

Exemplo: uma loja imprime `https://minhaloja.com.br/cardapio` em um QR Code estático. Se mantiver essa URL ativa e atualizar o conteúdo da página, o mesmo código impresso continuará útil. Se alterar o endereço para `/menu-novo` sem criar redirecionamento, precisará corrigir o destino no próprio site ou substituir a impressão.

## O que significa QR Code dinâmico?

Um serviço dinâmico costuma gerar um código com a URL de um redirecionador. Ao escanear, o usuário passa por esse endereço e é encaminhado a outro. O painel do serviço pode permitir trocar o destino, programar regras ou registrar visitas.

Esse modelo pode ser conveniente em campanhas que mudam frequentemente, mas depende do funcionamento do intermediário. É importante verificar política de preços, domínio utilizado, possibilidade de exportar dados e o que acontece caso a assinatura do serviço termine.

Não presuma que "dinâmico" significa necessariamente mais seguro. O controle para alterar o destino exige proteção da conta e manutenção de redirecionamentos confiáveis.

## Uma comparação prática

- **Material que não muda:** um QR Code estático costuma atender bem a um documento, cartão ou tutorial permanente.
- **Conteúdo hospedado no seu domínio:** um estático que aponta para uma URL sua pode ser atualizado por você sem recriar o código.
- **Campanha com muitos destinos temporários:** um serviço de redirecionamento pode facilitar alterações, desde que você aceite a dependência externa.
- **Pagamento Pix estático:** use um gerador apropriado, valide todos os dados e confirme o recebedor no app bancário.

## A alternativa que muita gente esquece

Ter seu próprio site traz flexibilidade. Você pode criar um QR Code estático para uma URL curta e estável — por exemplo, `sualoja.com.br/contato` — e manter o conteúdo dessa página atualizado. Dessa forma, não precisa necessariamente contratar um gerador dinâmico para trocar informações no destino.

O QR Livre gera códigos estáticos e oferece exportação em PNG, JPEG ou SVG. Se estiver planejando imprimir algo para uso por muitos meses, defina primeiro uma URL duradoura, documente onde ela é utilizada e teste o código em tamanho real.
